# Фан-сайт "Гори Вище"

Сайт аматорського вело-спринту вгору Смородинським узвозом.

Статичний двомовний односторінковий сайт без збірки та зовнішніх залежностей.

## Запуск локально

Поставити [Python](https://www.python.org/) та запустити:

```sh
python3 -m http.server 8003 --directory .
```

Відкрийте http://localhost:8003 у браузері.

## Зображення

Кожне фото зберігається у двох форматах і двох розмірах — сайт віддає перевагу
WebP і використовує прев’ю в галереї:

- `assets/NAME.jpg` та `assets/NAME.webp` — повний розмір;
- `assets/thumbs/NAME.jpg` та `assets/thumbs/NAME.webp` — прев’ю.

Додаючи нове фото в `GALLERY_IMAGES`, згенеруйте всі чотири файли.

## Деплой

Відбувається через Cloudflare Pages.
